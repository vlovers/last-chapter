# LAST CHAPTER — Narrative State Contract v1.0

## Незмінні факти та змінні інтерпретації

**WorldTruth** зберігає канон: лист написаний Айріс; не доставлений через протікання; зради Томаса не було. Ці поля не змінюються рішеннями. **Knowledge** окремо фіксує для кожного персонажа: невідомо / припускає / чув / бачив доказ / підтвердив. Чутка ніколи автоматично не перетворюється на факт.

## Структура майбутнього стану

- `seasonId`, `day`, `sceneId`, `schemaVersion`.
- `conversationHistory`: ключ сцени, пройдені теми, позиції гравця, запитані уточнення; жодного дублювання нагород за повтор.
- `relationship`: не універсальна «любов», а окремо `familiarity`, `trust`, `boundariesRespected` і конкретні обіцянки.
- `evidence`: походження, дата отримання, власник, чи було дозволено ознайомлення.
- `rumors`: твердження, джерело, коло поширення, статус перевірки.
- `letters`: `found`, `openedWithoutConsent`, `returnedToIris`, `deliveredToLeo`, `disclosedOpening`.
- `community`: відвідані читання, підтримані ініціативи, книжкові рекомендації.
- `epilogueInputs`: незалежні наслідки арок.

## Правила

1. `openedWithoutConsent` не можна скинути добрим вчинком; можна чесно визнати і частково відновити довіру.
2. `deliveredToLeo` не означає `LeoChoosesIris`. Романтичні рішення ухвалюють персонажі.
3. Нора ніколи не розкриває факт чи зміст чужих консультацій.
4. Повтор теми не породжує нових доказів.
5. Відсутність відвіданої теми не може бути витлумачена як згода гравця.
6. Книжкова рекомендація впливає на розмову й подальший відгук, а не магічно «лікує» персонажа.
7. Епілоги компонуються з незалежних наслідків. Не зводити все до однієї шкали «хорошого фіналу».

## Сумісність сезонів

Експортувати лише явні публічні підсумки та погоджені особисті зв’язки, не всі внутрішні прапорці. Кожна нова версія стану має міграцію й тести. Перший сезон працює автономно без майбутніх глав.
