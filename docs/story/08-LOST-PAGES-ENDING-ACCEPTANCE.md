# «Загублені сторінки»: критерії завершення першого сезону

Цей документ — редакторський контрольний список для фінального проходження, а не твердження, що браузерні тести вже пройдені.

## Факти, які фінал має розрізняти

| Твердження                                                   | Статус                             | Як говорити у фіналі                           |
| ------------------------------------------------------------ | ---------------------------------- | ---------------------------------------------- |
| Позначка «17» пов'язана з коробкою книгарні після затоплення | Підтверджено журналом Елеонори     | «Тепер ми знаємо, звідки взявся номер»         |
| Саме цей аркуш поклали між романами під час ремонту          | Імовірна реконструкція, без свідка | «Мабуть, він потрапив туди під час прибирання» |
| Позначку залишила авторка рукопису                           | Не доведено                        | Не приписувати їй цифру                        |
| Напис «Не віддавай їм останню сторінку» зробила Елеонора     | Не доведено                        | Вона не впізнає почерку                        |
| Другий уривок — справжній фінал                              | Не доведено                        | Не оголошувати його фіналом навіть після чуток |
| Лист Айріс до Лео залишився в книжці під час затоплення      | Спільний контекст події            | Не називати це доказом змови                   |

## Послідовність

1. День 1: звичайні замовлення та лист; персонажі ще не знають розгадки.
2. День 3: розмова про затоплення і знахідка після клубу або альтернативного вечора.
3. День 4: Айріс розповідає про рукописи; не знає майбутніх результатів п'ятого дня.
4. День 5: версії → журнал → рішення, чи показувати запис Айріс → рішення щодо оригіналів → необов'язкова передача архіву.
5. Якщо чутка пішла від Міллер, розмова Айріс про неї відбувається тільки після її поширення; виправлення не стирає наслідків.

## Матриця наслідків для ручного й автоматизованого QA

| Шлях                      | Обов'язкова реакція                     | Заборонена реакція                     |
| ------------------------- | --------------------------------------- | -------------------------------------- |
| Журнал не показано Айріс  | Вона не має доступу до нового запису    | Репліка, ніби вона його прочитала      |

## Голоси й атмосфера

- Айріс може образитися, відмовити або промовчати. Вона не зобов'язана дякувати за кожну дію.
- Елеонора визнає помилку без монологу з мораллю.
- Нора помічає деталі, але не знає більше, ніж бачила.
- Мара має право говорити про книжки, випічку й своє життя, а не лише про докази.
- Френк живе в книгарні, але не розгадує справу за гравця.
- У кожному вузлі не більше чотирьох варіантів вибору; повторні розмови після збереження не відкривають завершених рішень.

## Критерій приймання

Пройти всі п'ять днів мінімум за трьома маршрутами: обережний щодо приватності, із запущеною та виправленою чуткою, із запущеною та невиправленою чуткою. Перевірити повернення після збереження на п'ятому дні, епілоги, ліміти виборів і відсутність передчасних знань. Запустити `npm run check` і browser QA; зафіксувати конкретні результати CI перед злиттям.
