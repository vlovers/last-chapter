# Pixel portrait vertical slice

Eight original 64×80 SVG pixel-grid portraits are now shipped as local assets under `public/art/portraits/`. They are drawn from basic shapes, with individual color palettes, hairstyles, and optional glasses; no external media licensing is needed. Dialogue renders them as decorative images beside semantic Ukrainian speaker names.

**Scope:** static bust portraits, not animated expression sheets. The faces are intentionally simplified; stronger likeness differentiation, expressions (neutral, joyful, concerned, reflective), and artist review are still required.

**QA:** run `npm run check`, review all eight assets in browser at desktop and 320px, verify keyboard/screen reader, and check high-DPI pixel scaling. No successful CI or visual review is asserted by this document.
