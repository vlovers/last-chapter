# Art direction V3 — original pixel bookstore

The old room was a sparse 480×270 SVG with identical book rectangles, no background props and almost no sense of shop life. V3 replaces it with an independently authored 640×360 SVG featuring layered city silhouettes, lit windows, a postcard noticeboard, floor planks, a deeper shelf stocked with uneven book spines, books stacked on the counter, a register, envelope, mug, biscuits, hanging ivy, leafy plant and architectural details.

Hotspot controls now show small in-world symbols, while retaining Ukrainian accessible labels, titles, focus styles and existing click behavior. Scene layout is calmer with fewer dashboard-like rounded boxes.

**Important:** This is an art and UX iteration, not a complete game-quality asset pack. The game still needs original animated character sprites, expressive portrait work and proper browser visual regression testing. Run `npm run check` and inspect responsive screenshots before shipping.

No third-party game assets were used.
