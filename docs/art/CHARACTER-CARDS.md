# Character dialogue cards — visual slice

Eight recurring characters now have consistent, Ukrainian-language dialogue identities. Each speaker receives a decorative monogram and motif in a distinct color palette; the spoken text and speaker name remain semantic HTML. The narrator continues to use the existing plain dialogue style.

This is **not** a finished portrait set. The placeholders are intentionally original and asset-free, avoiding premature likeness or licensing assumptions. Portrait illustrations, expressions, emotional variants and dialogue transitions remain future work.
