# Testing

`npm test`: Vitest pure state transitions. `npm run lint`: ESLint. `npm run typecheck`: TypeScript. `npm run format:check`: Prettier. `npm run build`: Vite compile/bundle. `npm run check`: quality gate.

The initial tests cover rumor provenance, deterministic choices, and day/evening phase progression. Browser tests and save/load regression tests are **not configured**. Add them with substantive new UI and persistent story features, and exercise narrative continuity/knowledge gating in deterministic fixtures.

**Validation status:** not run against installed project dependencies in bootstrap environment (registry unavailable). GitHub CI status must be checked after opening PR; do not infer success from workflow existence.
