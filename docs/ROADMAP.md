# Roadmap

## Foundation (initial PR)

- [x] Minimal browser-first structure, interaction spike and separated deterministic game rules.
- [x] Agent instructions, engineering docs, PR/issue templates and initial CI definition.
- [x] Unit test source for rumor provenance and phase transitions.
- [x] Generate committed lockfile and use `npm ci` in CI.
- [x] Verify format, lint, typecheck, 23 unit tests, production build and security audit in the controlled bootstrap workflows.
- [ ] Verify final pull-request CI after dependency upgrade.

## Narrative-first vertical slice

- [ ] Story Bible: coherent small-town chronology, objective truth, secrets, ethical conflicts.
- [ ] Character Bible: 6–8 recurring visitors, identities, voices, knowledge boundaries.
- [ ] Dialogue Bible: optional topics, conditional disclosures, conversational pacing.
- [ ] 15–20 fictional books with descriptions and plausible recommendation reasons.
- [ ] Rumor spread and knowledge-provenance state, consequences tested.
- [ ] 2–3 investigations with fair clue trails and alternate outcomes.
- [ ] Timed playtest targeting ~40 minutes, prose review.

## Game presentation

- [ ] Coherent production pixel-art scenes with licensed provenance.
- [ ] Responsive and accessible dialogue, catalog and evening notebook UI.
- [x] Prototype versioned local browser saves (no event-log verification or migrations yet).
- [ ] Production save migrations and seeded variants.
- [ ] Ukrainian-only (uk-UA) game content and UI; editorial and accessibility QA. English game localization is out of scope.
- [ ] Browser regression test automation.

## Later

- [ ] Art/audio polish, accessibility review, release strategy and security assessment.

**Current limitation:** the browser has a short Ukrainian first-day prototype with two visitors, five book cards, an evening mystery and local saves. It is not a finished long-form story or a pixel-art release.
