# Security Policy

Early-stage local browser prototype; no production service, authentication or credentials.

Use GitHub's private vulnerability reporting feature if available; otherwise request a private communication channel from maintainers without posting exploit details publicly. No response SLA is asserted.

Treat imported story content, save files and any eventual user input as untrusted. Prefer DOM `textContent` for dynamic prose. Do not add secrets, analytics, tracking, payments or hosted services without explicit review.
